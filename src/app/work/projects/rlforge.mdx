## Overview

RLForge is a full-stack reinforcement learning simulation platform designed to easily streamline advanced reinforcement learning setups for both researchers and engineers. 

## Key Features

- **Bidirectional Streaming**: Real-time bidirectional WebSocket microservice that flawlessly streams multi-dimensional action-spaces and headless EGL graphic frames with low latency.
- **Dynamic CI Pipeline**: Engineered a continuous integration pipeline leveraging multi-stage Docker builds to sandbox heavy compiled physics engines (Mujoco/Box2D).
- **Environment Management**: Ensures cross-platform parity and zero-configuration environment installations directly through an intuitive React GUI.

## Technologies Used

- **Frontend**: React, TypeScript
- **Backend**: FastAPI, Python, WebSockets
- **Infrastructure**: Docker
- **RL/Simulation**: Gymnasium, Mujoco, Box2D
