## Overview

ztf-js is a cutting-edge zero trust security framework engineered explicitly for modern TypeScript and JavaScript applications. It ensures stringent identity and access verifications are executed efficiently at every boundary, granting zero inherent trust. 

## Key Features

- **Zero Trust Security**: Minimizes common attack vectors by enforcing rigid, identity-based access controls by default.
- **High Performance**: Integrates seamlessly with a Redis-based cache to accelerate permission verifications and rate-limitings securely with minimal latency.
- **Ecosystem Integration**: Designed to be integrated natively into existing TS/JS backend environments with ease.

## Technologies Used

- **Language**: TypeScript / JavaScript
- **Infrastructure**: Redis
- **Platform**: Node.js
