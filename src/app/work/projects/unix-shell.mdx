## Overview

A robust Unix-like shell providing command execution, environment variable handling, and native OS integrations directly built with Java without external dependencies. 

## Key Features

- **Command Execution**: Supported command execution, argument parsing, pipes, and basic built-ins.
- **Process Management**: Utilizing Java's ProcessBuilder and stream handling to maintain stable execution paths.
- **Built-in Parser**: Implemented a lightweight command parser and REPL loop to manage processes, I/O redirection, and error handling mimicking an OS-style environment.

## Technologies Used

- **Language**: Java
- **Concepts**: Processes, I/O Streams, System Programming
